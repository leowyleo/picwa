这份政策描述 Picrow 作为本地优先 macOS 图片时间线工具时如何处理信息。

## 我们处理什么信息

Picrow 只处理用户主动选择的文件夹中的图片文件。为了建立时间线，应用会在本机读取图片的文件名、路径、尺寸和创建时间等元数据，并在本机保存图片索引。

Picrow 还会在本机保存用户选择的文件夹授权、忽略位置和浏览设置，以便下次启动时恢复。

## 我们不会做什么

- 不上传图片、图片元数据或索引。
- 不使用广告、跨应用跟踪或第三方分析服务。
- 不要求账号、联系人、照片图库或位置权限。
- 不在后台自动删除文件。

## 文件操作

扫描仅发生在用户授权的文件夹内。复制和删除操作只会在用户明确执行后发生；删除使用 macOS 废纸篓流程。Picrow 不会自动选择或自动删除重复图片。

## 本地数据

文件夹授权、扫描设置和图片索引保存在 Picrow 的 macOS 沙盒容器中，仅供本机 Picrow 使用。用户可以在设置中移除已添加的文件夹，也可以卸载应用以移除应用容器中的数据。

## English summary

Picrow is a local-first macOS photo timeline. It processes images only in folders the user explicitly selects, reads image metadata on the Mac, and stores the index and folder permissions locally. Picrow does not upload images or indexes, use advertising or third-party analytics, track users across apps, or delete files automatically. Copy and delete actions occur only after the user explicitly requests them.
