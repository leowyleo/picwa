# Picrow 商店素材清单

## 已有

- App 图标源图：`Resources/AppIcon-Source.png`
- macOS `.icns`：`Resources/AppIcon.icns`
- 标准图标尺寸：16、32、64、128、256、512、1024 px

## 需要制作

Mac App Store 截图至少准备一组真实应用界面，建议使用 1440 × 900 或 2880 × 1800。截图必须来自当前版本，不使用占位图或与功能不一致的画面。

建议顺序：

1. 空状态与“从一个文件夹开始”
2. 图片时间线与真实日期分组
3. 多选、复制和访达操作
4. 设置页的包含/忽略目录管理
5. 本地隐私与不自动删除说明

- [ ] 所有截图与提交版本一致
