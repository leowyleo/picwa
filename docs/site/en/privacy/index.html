Picrow is a local-first photo timeline for macOS.

What Picrow processes

Picrow processes image files only in folders you explicitly choose. To build the timeline, it reads local metadata such as file names, paths, dimensions, and creation dates, and stores the image index on your Mac.

Picrow also stores the folder permissions, ignored locations, and browsing settings needed to restore your workspace.

What Picrow does not do

  • It does not upload images, image metadata, or indexes.
  • It does not use advertising, cross-app tracking, or third-party analytics.
  • It does not require an account, contacts, Photos library, or location access.
  • It does not delete files automatically in the background.

File operations

Scanning is limited to folders you authorize. Copy and delete actions happen only after you explicitly perform them; deletion uses the macOS Trash flow. Picrow never auto-selects or automatically deletes duplicate photos.

Local data

Folder permissions, scan settings, and the image index are stored in Picrow’s macOS sandbox container for use by Picrow on this Mac. You can remove added folders in Settings or uninstall the app to remove its container data.
