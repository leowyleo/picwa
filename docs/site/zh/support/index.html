开始使用

点击“添加文件夹”，选择包含图片的文件夹。Picrow 只扫描你主动授权的文件夹，并按图片的真实创建时间建立时间线。

文件没有显示

  • 确认选择的是包含图片的文件夹，而不是文件本身。
  • 确认图片格式受 macOS ImageIO 支持。
  • 如果刚刚添加了大量图片，请等待索引完成。

隐私与文件安全

原始图片始终留在你的 Mac 上。Picrow 不上传图片，也不会自动删除文件。完整说明请查看隐私政策。

联系

如需报告可复现问题或提出隐私请求，请通过 GitHub 上的 Picrow Issues 或邮件至 leowy.lwy@gmail.com 联系。
